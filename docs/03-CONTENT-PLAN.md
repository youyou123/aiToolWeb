## 文章结构模板（每篇统一）

```
1. 开头 100 词：直接回答「哪个最好」
2. Quick Comparison 表格（5 个工具）
3. 逐个工具：优点 / 缺点 / 价格 / 适合谁
4. How to Choose 小节
5. FAQ（3–5 个）
6. 结尾 CTA：推荐 #1 工具 + 联盟按钮
```

---

## SEO 基础（Rank Math 里填）

- Focus Keyword：标题里的主词
- Meta Description：155 字符内，含关键词
- 内链：新文章链到至少 2 篇旧文章
- 外链：链到工具官网 1–2 个（增信任）
