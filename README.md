# AI Tools Monetize — 英文 AI 工具站变现项目

低成本、快速变现：WordPress + 广告 + Affiliate 联盟。

## 目标

| 指标 | 第1月 | 第3月 | 第6月 |
|------|-------|-------|-------|
| 月访客 | 500–2,000 | 5,000–15,000 | 20,000+ |
| 月收入 | $5–80 | $100–500 | $400–1,500 |

## 本地预览

```powershell
cd F:\outapp\ai-tools-monetize
.\start.ps1
# 或
npm start
# 或
cd site && python -m http.server 8080
```

浏览器打开：**http://localhost:8080**

## 项目结构

```
site/           本地可运行的静态站预览
docs/           操作手册（按顺序看）
content/        文章草稿与模板
CHECKLIST.md    每日/每周任务打勾
start.ps1       一键启动本地服务
```

## 今天就开始（3 步）

1. 打开 `docs/01-DAY1-SETUP.md`，完成域名 + WordPress + 广告注册
2. 打开 `docs/02-AFFILIATE-APPLY.md`，申请联盟账号（**编程线优先 DigitalOcean**）
3. **首发文章**：`content/article-c1-claude-code-vs-codex-vs-cursor.md`（已写好，改链接即发）
4. 引流：`docs/07-C1-LAUNCH-TRAFFIC.md`

## 变现组合

- **广告**：Adsterra Push（低门槛）→ 有流量后换 Ezoic
- **联盟**：Amazon Associates + AI SaaS 官方联盟（Jasper、Notion 等）
- **会员**：第 6 月后再加（Paid Memberships Pro）
